# SonaWills

SonaWills is an AI music-video studio designed to turn music, character references, and a creative prompt into cinematic music videos up to 5 minutes.

## Planned pipeline

1. Upload music and analyze mood, structure, lyrics and timing.
2. Upload character reference images and establish identity anchors.
3. Generate a scene/shot plan based on the audio and creative prompt.
4. Generate short video shots while preserving character continuity.
5. Add performance and lip-sync shots where appropriate.
6. Assemble shots to the original audio with transitions and FFmpeg.
7. Export a downloadable MP4.

## Development principle

SonaWills will prioritize open-source models and free infrastructure where practical. It will not claim unlimited free GPU generation when an underlying service has resource costs or usage limits.

## Status

Initial repository setup. The application architecture and implementation will be added incrementally.
